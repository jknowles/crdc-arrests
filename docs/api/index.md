# CRDC School Arrest Rate Estimates — API & Data

Bayesian small-area estimates of school-based arrest rates (CRDC, 2015–16 /
2017–18 / 2021–22). Query without running the models.

- **Live API:** https://crdc-api.civilytics.org/api/v1/ (Swagger: https://crdc-api.civilytics.org/__docs__/)
- **Agent guide:** https://crdc-api.civilytics.org/api/v1/llms.txt
- **Data dictionary:** [data-dictionary.md](./data-dictionary.md)
- **Bulk downloads (Hugging Face):** https://huggingface.co/datasets/civilytics/crdc-school-arrest-rates
  - `summary.duckdb` (compact estimates) and `parquet/` (full posterior draws)

Cite: Knowles & Miller 2025. Supported by AERA/NSF (NSF-DRL #1749275).
